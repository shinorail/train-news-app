# 篠ノ井乗務区 Train-News (PWA版)

篠ノ井乗務区の新聞記事・ニュースを閲覧できるWebアプリ（PWA）です。

---

## 📱 アプリの特徴・利用方法

### 💻 Windows / PC
* ブラウザからそのまま最新のニュース記事・PDFを閲覧できます。

### 📱 スマートフォン・タブレット
* **ホーム画面に追加（PWAインストール）** することで、専用の新聞アプリとしてサクサク閲覧できます。
  * **iPhone (Safari):** 共有ボタン ➔「ホーム画面に追加」
  * **Android (Chrome):** メニュー ➔「アプリをインストール」

---

## 🛠 機能一覧
* 📰 **新聞一覧・閲覧:** 最新の鉄道ニュースや号外記事の閲覧
* 🔒 **会員限定記事:** ログイン機能による限定公開記事の閲覧
* ⭐ **お気に入り機能:** 気になる記事を保存
* 💬 **コメント機能:** 記事に対する感想やコメントの投稿・公式返信表示
* ⚡ **PWA対応:** オフラインキャッシュ & アプリライクな起動
